# javascript-calculator-precourse
# 1주차 - 문자열 덧셈 계산기

## ⚙️ 간단한 프로젝트 실행 흐름
1. 안내 문구를 출력한다.
2. 사용자 입력을 수신한다.
3. 입력 문자열을 parser로 넘겨 숫자 배열로 변환한다.
4. 숫자 배열을 validator로 검증한다.
5. 검증 통과 배열을 calculator로 합산한다.
6. 합산 결과를 지정된 포맷으로 출력한다.
7. 프로세스를 종료한다.
